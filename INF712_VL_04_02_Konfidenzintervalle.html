1 Vorlesung 04-02: Konfidenzintervalle

Definition und Interpretation, allgemeine Konstruktion, Konfidenzintervalle für einen Mittelwert und für die Differenz zweier Mittelwerte, Wahl des Stichprobenumfangs (Baron, §9.2).

Lernziele

Nach dieser Vorlesung können Sie

  • erklären, was ein Konfidenzniveau aussagt — und was nicht,
  • aus einem erwartungstreuen, normalverteilten Schätzer ein Konfidenzintervall konstruieren,
  • Konfidenzintervalle für einen Mittelwert und für die Differenz zweier Mittelwerte berechnen,
  • per Simulation prüfen, ob ein Intervallverfahren sein Konfidenzniveau tatsächlich einhält,
  • den Stichprobenumfang bestimmen, der eine vorgegebene Genauigkeit garantiert.

1.1 Rückblick: Schätzer und Standardfehler

In der letzten Vorlesung haben wir Parameter geschätzt. Drei Punkte daraus brauchen wir heute:

  • Ein Schätzer \(\hat\theta\) ist eine Zufallsvariable — jede Stichprobe liefert einen anderen Wert.
  • Erwartungstreu heißt \(E(\hat\theta) = \theta\): Der Schätzer liegt im Mittel richtig.
  • Der Standardfehler \(\sigma(\hat\theta)\) misst, wie stark er um \(\theta\) schwankt.

Für den Stichprobenmittelwert gilt \(E(\bar X) = \mu\) und \(\sigma(\bar X) = \sigma/\sqrt n\); nach dem zentralen Grenzwertsatz ist \(\bar X\) für großes \(n\) näherungsweise normalverteilt. Eine kurze Simulation mit \(\mu = 50\), \(\sigma = 8\) und \(n = 25\) zeigt, was daraus folgt:

set.seed(1)
mu <- 50; sigma <- 8; n <- 25
xq <- replicate(10000, mean(rnorm(n, mu, sigma)))

c(mittel = mean(xq), sd = sd(xq), theorie_se = sigma / sqrt(n))
#>     mittel         sd theorie_se 
#>  49.990819   1.590205   1.600000
mean(abs(xq - mu) <= 1.96 * sigma / sqrt(n))   # Anteil innerhalb von 1.96 SE
#> [1] 0.9502

In rund 95 % der Stichproben liegt \(\bar X\) höchstens \(1{,}96\,\sigma/\sqrt n\) von \(\mu\) entfernt. Dann liegt umgekehrt auch \(\mu\) höchstens \(1{,}96\,\sigma/\sqrt n\) von \(\bar X\) entfernt — und genau das ist ein Konfidenzintervall. Diese Umkehrung ist die ganze Idee der heutigen Vorlesung.

1.2 Konfidenzintervalle: Idee und Konstruktion

Von der Punktschätzung zum Intervall

Ein Schätzwert \(\hat\theta\) ist fast sicher nicht gleich \(\theta\). Statt einer einzelnen Zahl geben wir deshalb ein Intervall an, das den Parameter mit hoher, bekannter Wahrscheinlichkeit enthält.

Definition (Baron 9.4). Ein Intervall \([a, b]\) ist ein \((1-\alpha)100\,\%\)-Konfidenzintervall für \(\theta\), wenn \[P(a \le \theta \le b) = 1 - \alpha.\] \(1 - \alpha\) heißt Konfidenzniveau (Überdeckungswahrscheinlichkeit).

Was ist hier zufällig?

Der Parameter \(\theta\) ist fest — eine Eigenschaft der Population. Zufällig sind die Intervallgrenzen \(a\) und \(b\), denn sie werden aus der zufälligen Stichprobe berechnet. Das Konfidenzniveau ist also eine Aussage über das Verfahren: Wiederholt man die Datenerhebung sehr oft, überdecken \((1-\alpha)100\,\%\) der Intervalle den wahren Wert.

Das ist Barons Abbildung 9.2 — als Simulation mit 100 Stichproben (\(n = 10\), \(\mu = 50\), \(\sigma = 8\)) und 90-%-Intervallen:

set.seed(13)
mu <- 50; sigma <- 8; n <- 10; niveau <- 0.90
z <- qnorm(1 - (1 - niveau) / 2)

grenzen <- t(replicate(100, {
  xq <- mean(rnorm(n, mu, sigma))
  c(unten = xq - z * sigma / sqrt(n), oben = xq + z * sigma / sqrt(n))
}))
trifft <- grenzen[, "unten"] <= mu & mu <= grenzen[, "oben"]

plot(NA, xlim = range(grenzen), ylim = c(1, 100), yaxt = "n",
     xlab = expression(mu), ylab = "Stichprobe",
     main = sprintf("100 Konfidenzintervalle (90 %%): %d überdecken mu", sum(trifft)))
segments(grenzen[, "unten"], 1:100, grenzen[, "oben"], 1:100,
         col = ifelse(trifft, "grey40", "firebrick"), lwd = ifelse(trifft, 1, 2.5))
abline(v = mu, col = "steelblue", lwd = 2)

Die roten Intervalle verfehlen \(\mu\) — nicht wegen eines Fehlers, sondern allein durch den Stichprobenzufall.

WarnungDie häufigste Fehlinterpretation

Falsch: „Ich habe das 90-%-Intervall \([3, 6]\) berechnet; der Parameter liegt mit 90 % Wahrscheinlichkeit darin.”

Nach der Berechnung ist nichts mehr zufällig: \(\theta\) liegt entweder in \([3, 6]\) oder nicht. Richtig: „Das Verfahren liefert Intervalle, die in 90 % aller Stichproben den wahren Wert enthalten.” Die 90 % beschreiben die Methode, nicht dieses eine Intervall.

Die allgemeine Konstruktion (Baron, §9.2.1)

Ist \(\hat\theta\) erwartungstreu und normalverteilt, dann ist

\[ Z = \frac{\hat\theta - \theta}{\sigma(\hat\theta)} \sim N(0, 1). \]

\(Z\) liegt mit Wahrscheinlichkeit \(1-\alpha\) zwischen den Quantilen \(-z_{\alpha/2}\) und \(z_{\alpha/2}\), wobei \(z_{\alpha/2} = \Phi^{-1}(1 - \alpha/2)\) der Wert ist, der mit Wahrscheinlichkeit \(\alpha/2\) überschritten wird:

\[ P\!\left(-z_{\alpha/2} \le \frac{\hat\theta - \theta}{\sigma(\hat\theta)} \le z_{\alpha/2}\right) = 1 - \alpha. \]

Auflösen der Ungleichungen nach \(\theta\) ergibt die zentrale Formel

\[ \boxed{\;\hat\theta \pm z_{\alpha/2}\cdot\sigma(\hat\theta)\;} \qquad\text{(Baron, 9.3)} \]

Man nennt \(\hat\theta\) den Mittelpunkt und \(z_{\alpha/2}\cdot\sigma(\hat\theta)\) die Fehlermarge (margin of error), wie sie bei Umfragen berichtet wird. Ist \(\hat\theta\) nur näherungsweise normalverteilt, ist auch das Intervall nur näherungsweise ein \((1-\alpha)100\,\%\)-Intervall.

alpha <- 0.05
z <- qnorm(1 - alpha / 2)
curve(dnorm(x), from = -3.5, to = 3.5, lwd = 2, xlab = "z", ylab = "Dichte",
      main = expression("Standardnormalverteilung und " %+-% z[alpha/2]))
xs <- seq(-z, z, length.out = 200)
polygon(c(-z, xs, z), c(0, dnorm(xs), 0), col = "lightsteelblue", border = NA)
abline(v = c(-z, z), lty = 2)
text(0, 0.15, expression(1 - alpha))
text(c(-2.8, 2.8), 0.05, expression(alpha / 2))

Quantile in R statt Tabelle

Die Quantile aus Barons Tabelle A4 liefert qnorm():

niveaus <- c(0.80, 0.90, 0.95, 0.98, 0.99)
data.frame(niveau = niveaus, alpha = 1 - niveaus,
           z = round(qnorm(1 - (1 - niveaus) / 2), 3))

Merken sollte man sich \(z_{0{,}05} = 1{,}645\) (90 %), \(z_{0{,}025} = 1{,}960\) (95 %) und \(z_{0{,}005} = 2{,}576\) (99 %).

Rezept (Baron, §9.2.1)

  1. Einen erwartungstreuen Schätzer \(\hat\theta\) finden.
  2. Prüfen, ob er (näherungsweise) normalverteilt ist.
  3. Seinen Standardfehler \(\sigma(\hat\theta)\) bestimmen.
  4. Das Quantil \(z_{\alpha/2}\) bestimmen (qnorm(1 - alpha/2)).
  5. \(\hat\theta \pm z_{\alpha/2}\,\sigma(\hat\theta)\) berechnen.

1.3 Konfidenzintervall für einen Mittelwert (\(\sigma\) bekannt)

Für \(\theta = \mu\) ist \(\hat\theta = \bar X\) erwartungstreu mit \(\sigma(\bar X) = \sigma/\sqrt n\). Normalverteilt ist \(\bar X\) in zwei Fällen:

  1. Die Daten sind normalverteilt — dann ist \(\bar X\) exakt normal.
  2. Der Stichprobenumfang \(n\) ist groß — dann ist \(\bar X\) nach dem zentralen Grenzwertsatz näherungsweise normal.

\[ \bar X \pm z_{\alpha/2}\,\frac{\sigma}{\sqrt n} \qquad\text{(Baron, 9.5)} \]

ki_mittelwert <- function(x, sigma, niveau = 0.95) {
  z <- qnorm(1 - (1 - niveau) / 2)
  marge <- z * sigma / sqrt(length(x))
  c(mittelwert = mean(x), marge = marge,
    unten = mean(x) - marge, oben = mean(x) + marge)
}

Beispiel (Baron, Bsp. 9.13). Messungen \(2{,}5;\ 7{,}4;\ 8{,}0;\ 4{,}5;\ 7{,}4;\ 9{,}2\) mit normalverteilten Messfehlern; das Messgerät garantiert \(\sigma = 2{,}2\). Gesucht ist ein 95-%-Konfidenzintervall für \(\mu\).

messung <- c(2.5, 7.4, 8.0, 4.5, 7.4, 9.2)
round(ki_mittelwert(messung, sigma = 2.2, niveau = 0.95), 2)
#> mittelwert      marge      unten       oben 
#>       6.50       1.76       4.74       8.26

Ergebnis: \(6{,}50 \pm 1{,}76\), also \([4{,}74;\ 8{,}26]\) — wie bei Baron.

Hält das Verfahren sein Versprechen?

Wir prüfen die Überdeckung per Simulation. Bei normalverteilten Daten sollte sie für jedes \(n\) bei 95 % liegen:

ueberdeckung <- function(zufall, mu, sigma, n, R = 10000, niveau = 0.95) {
  z <- qnorm(1 - (1 - niveau) / 2)
  treffer <- replicate(R, {
    xq <- mean(zufall(n))
    abs(xq - mu) <= z * sigma / sqrt(n)
  })
  mean(treffer)
}

set.seed(14)
sapply(c(n_3 = 3, n_10 = 10, n_50 = 50),
       function(n) ueberdeckung(function(k) rnorm(k, 6.5, 2.2), 6.5, 2.2, n))
#>    n_3   n_10   n_50 
#> 0.9532 0.9521 0.9504

Und bei nicht normalverteilten Daten?

Baron warnt: Für kleine Stichproben aus nicht normalverteilten Populationen gilt die Formel nicht. Wie äußert sich das? Wir verwenden stark schiefe exponentialverteilte Daten (\(\mu = \sigma = 1\)) und zählen getrennt, wie oft das Intervall zu hoch bzw. zu tief liegt:

fehlerseiten <- function(n, R = 20000, niveau = 0.95) {
  z <- qnorm(1 - (1 - niveau) / 2)
  r <- replicate(R, {
    xq <- mean(rexp(n, rate = 1))
    marge <- z * 1 / sqrt(n)
    c(zu_hoch = xq - marge > 1, zu_tief = xq + marge < 1)
  })
  c(ueberdeckung = 1 - mean(colSums(r) > 0),
    zu_hoch = mean(r["zu_hoch", ]), zu_tief = mean(r["zu_tief", ]))
}

set.seed(15)
round(t(sapply(c(n_5 = 5, n_10 = 10, n_30 = 30, n_100 = 100, n_1000 = 1000),
               fehlerseiten)), 4)
#>        ueberdeckung zu_hoch zu_tief
#> n_5          0.9580  0.0412  0.0008
#> n_10         0.9550  0.0398  0.0052
#> n_30         0.9504  0.0346  0.0150
#> n_100        0.9530  0.0287  0.0184
#> n_1000       0.9514  0.0261  0.0226

Die Gesamtüberdeckung liegt erstaunlich nah bei 95 % — aber die Fehler sind einseitig: Bei \(n = 5\) liegt das Intervall in rund 4 % der Fälle zu hoch und fast nie zu tief. Erst bei großem \(n\) verteilen sich die Fehler gleichmäßig auf beide Seiten, so wie es bei einem symmetrischen Intervall sein soll. Wer aus einem solchen Intervall einseitige Schlüsse zieht (z. B. „\(\mu\) ist höchstens …“), irrt sich viel häufiger als in 2,5 % der Fälle.

set.seed(16)
par(mfrow = c(1, 2))
for (n in c(5, 100)) {
  xq <- replicate(10000, mean(rexp(n)))
  hist(xq, breaks = 50, freq = FALSE, col = "grey85",
       main = bquote("Verteilung von" ~ bar(X) ~ "bei" ~ n == .(n)),
       xlab = expression(bar(X)))
  curve(dnorm(x, 1, 1 / sqrt(n)), add = TRUE, col = "red", lwd = 2)
}
par(mfrow = c(1, 1))

1.4 Konfidenzintervall für die Differenz zweier Mittelwerte

Oft vergleicht man zwei Populationen: zwei Server, zwei Algorithmen, zwei Konfigurationen, vor und nach einem Update. Aus jeder Population wird unabhängig eine Stichprobe gezogen, \(X_1, \dots, X_n\) und \(Y_1, \dots, Y_m\). Gesucht ist ein Konfidenzintervall für \(\theta = \mu_X - \mu_Y\). Wir folgen dem Rezept:

  1. Schätzer: \(\hat\theta = \bar X - \bar Y\).
  2. Erwartungstreu: \(E(\bar X - \bar Y) = \mu_X - \mu_Y\).
  3. Normalverteilt, wenn beide Populationen normal sind oder beide Stichproben groß sind.
  4. Wegen der Unabhängigkeit addieren sich die Varianzen: \(\sigma(\hat\theta) = \sqrt{\sigma_X^2/n + \sigma_Y^2/m}\).
  5. Damit:

\[ \bar X - \bar Y \pm z_{\alpha/2}\sqrt{\frac{\sigma_X^2}{n} + \frac{\sigma_Y^2}{m}} \qquad\text{(Baron, 9.6)} \]

WichtigVarianzen addieren sich — auch bei einer Differenz

\(\operatorname{Var}(\bar X - \bar Y) = \operatorname{Var}(\bar X) + \operatorname{Var}(\bar Y)\), nicht die Differenz der Varianzen. Die Unsicherheit beider Stichproben kommt zusammen.

ki_differenz <- function(xq, yq, sigma_x, sigma_y, n, m, niveau = 0.95) {
  z <- qnorm(1 - (1 - niveau) / 2)
  marge <- z * sqrt(sigma_x^2 / n + sigma_y^2 / m)
  c(differenz = xq - yq, marge = marge,
    unten = xq - yq - marge, oben = xq - yq + marge)
}

Beispiel (Baron, Bsp. 9.14): Wirkung eines Hardware-Upgrades. Ein Prozess läuft 50-mal vor und 50-mal nach einem Upgrade. Die mittlere Laufzeit beträgt 8,5 Minuten vorher und 7,2 Minuten nachher; die Standardabweichung ist aus Erfahrung \(\sigma = 1{,}8\) Minuten (in beiden Fällen). Gesucht ist ein 90-%-Konfidenzintervall für die Verkürzung der mittleren Laufzeit.

round(ki_differenz(xq = 8.5, yq = 7.2, sigma_x = 1.8, sigma_y = 1.8,
                   n = 50, m = 50, niveau = 0.90), 2)
#> differenz     marge     unten      oben 
#>      1.30      0.59      0.71      1.89

Das Upgrade verkürzt die mittlere Laufzeit um 1,3 Minuten, mit einer 90-%-Fehlermarge von 0,6 Minuten: \([0{,}7;\ 1{,}9]\). Da das Intervall die 0 nicht enthält, ist eine echte Verbesserung plausibel.

Die Laufzeiten müssen dafür nicht normalverteilt sein — bei \(n = m = 50\) sorgt der zentrale Grenzwertsatz für die Normalität von \(\bar X - \bar Y\). Eine Simulation mit schiefen (gammaverteilten) Laufzeiten bestätigt das:

set.seed(17)
# Gammaverteilte Laufzeiten mit Mittelwert 8.5 bzw. 7.2 und sd 1.8
r_lauf <- function(n, mu, sd) rgamma(n, shape = (mu / sd)^2, rate = mu / sd^2)

treffer <- replicate(10000, {
  vorher  <- r_lauf(50, 8.5, 1.8)
  nachher <- r_lauf(50, 7.2, 1.8)
  ki <- ki_differenz(mean(vorher), mean(nachher), 1.8, 1.8, 50, 50, niveau = 0.90)
  ki["unten"] <= 1.3 & 1.3 <= ki["oben"]
})
mean(treffer)                            # Ziel: 0.90
#> [1] 0.9016

1.5 Wahl des Stichprobenumfangs

Jedes Konfidenzintervall dieser Vorlesung hat die Form Mittelpunkt ± Marge. Damit lässt sich die Frage umdrehen: Wie groß muss die Stichprobe sein, damit die Marge höchstens \(\Delta\) beträgt? Für den Mittelwert ist

\[ z_{\alpha/2}\frac{\sigma}{\sqrt n} \le \Delta \quad\Longleftrightarrow\quad n \ge \left(\frac{z_{\alpha/2}\,\sigma}{\Delta}\right)^2 \qquad\text{(Baron, 9.8)} \]

Das Ergebnis wird immer aufgerundet — beim Abrunden wäre die Marge größer als \(\Delta\).

n_benoetigt <- function(sigma, delta, niveau = 0.95) {
  z <- qnorm(1 - (1 - niveau) / 2)
  ceiling((z * sigma / delta)^2)
}

Beispiel (Baron, Bsp. 9.15). Das Intervall aus Bsp. 9.13 hatte die Marge 1,76 — zu breit. Wie groß muss die Stichprobe sein, damit die 95-%-Marge höchstens 0,4 beträgt?

(qnorm(0.975) * 2.2 / 0.4)^2             # exakter Wert
#> [1] 116.2041
n_benoetigt(sigma = 2.2, delta = 0.4)    # aufgerundet
#> [1] 117

Man braucht mindestens 117 Messungen.

Was treibt den Stichprobenumfang?

Ein großes \(n\) ist nötig für

  • eine kleine Marge \(\Delta\),
  • ein hohes Konfidenzniveau (kleines \(\alpha\)),
  • stark streuende Daten (großes \(\sigma\)).

Weil \(\Delta\) nur mit \(1/\sqrt n\) fällt, muss man den Stichprobenumfang vervierfachen, um die Marge zu halbieren — dieselbe \(1/\sqrt n\)-Regel wie beim Monte-Carlo-Fehler.

n_seq <- 1:200
plot(n_seq, qnorm(0.975) * 2.2 / sqrt(n_seq), type = "l", lwd = 2, log = "y",
     xlab = "Stichprobenumfang n", ylab = "Marge (log. Skala)",
     main = "95-%-Marge für sigma = 2.2")
lines(n_seq, qnorm(0.995) * 2.2 / sqrt(n_seq), lty = 2)
lines(n_seq, qnorm(0.95)  * 2.2 / sqrt(n_seq), lty = 3)
abline(h = 0.4, col = "red"); abline(v = 117, col = "red", lty = 3)
legend("topright", c("99 %", "95 %", "90 %"), lty = c(2, 1, 3), lwd = c(1, 2, 1),
       bty = "n")
outer(c(sigma_1 = 1, sigma_2 = 2, sigma_5 = 5),
      c(delta_1 = 1, delta_0.5 = 0.5, delta_0.1 = 0.1),
      Vectorize(function(s, d) n_benoetigt(s, d)))
#>         delta_1 delta_0.5 delta_0.1
#> sigma_1       4        16       385
#> sigma_2      16        62      1537
#> sigma_5      97       385      9604
HinweisAusblick: unbekanntes \(\sigma\)

Alle Intervalle dieser Vorlesung setzen ein bekanntes \(\sigma\) voraus — etwa aus der Genauigkeit eines Messgeräts oder aus vielen historischen Daten. Meist ist \(\sigma\) aber unbekannt und muss durch \(s\) geschätzt werden. Für große Stichproben ändert sich fast nichts; für kleine normalverteilte Stichproben ersetzt man \(z_{\alpha/2}\) durch das Quantil der \(t\)-Verteilung (Baron, §9.3; t.test()). Das ist Thema der nächsten Vorlesung.

1.6 Übungsaufgaben

Aufgaben mit Quellenangabe stammen aus Baron, Kapitel 9. Zu jeder Aufgabe gibt es eine aufklappbare Lösung. Versuchen Sie es zuerst selbst — von Hand und in R. Die Reiter Tipp, Lösung und Erklärung können Sie einzeln öffnen.

Aufgabe 1: Gleichzeitige Nutzer (Baron, Übung 9.7a). Zu 100 zufälligen Zeitpunkten waren im Mittel 37,7 Nutzer gleichzeitig auf einem Server; \(\sigma = 9{,}2\). Berechnen Sie ein 90-%-Konfidenzintervall für die erwartete Nutzerzahl.

Formel (9.5) mit \(z_{0{,}05} = 1{,}645\). Die Rohdaten brauchen Sie nicht — nur \(\bar x\), \(\sigma\) und \(n\).

z <- qnorm(0.95)                         # 90 %: alpha/2 = 0.05
marge <- z * 9.2 / sqrt(100)
c(z = z, marge = marge, unten = 37.7 - marge, oben = 37.7 + marge)
#>         z     marge     unten      oben 
#>  1.644854  1.513265 36.186735 39.213265

\(37{,}7 \pm 1{,}645 \cdot 9{,}2/\sqrt{100} = 37{,}7 \pm 1{,}51\), also \([36{,}19;\ 39{,}21]\).

Ob die Anzahl gleichzeitiger Nutzer normalverteilt ist, spielt keine Rolle: Bei \(n = 100\) ist \(\bar X\) nach dem zentralen Grenzwertsatz näherungsweise normalverteilt. Das Intervall sagt etwas über den Erwartungswert — einzelne Zeitpunkte mit 50 oder 20 Nutzern sind damit vereinbar (vgl. Aufgabe 2).

Aufgabe 2: Installationszeit (Baron, Übung 9.8). Die Installation einer Hardware dauert zufällig lang mit \(\sigma = 5\) Minuten. (a) Bei 64 Installationen betrug die mittlere Dauer 42 Minuten. Berechnen Sie ein 95-%-Konfidenzintervall für die mittlere Installationszeit. (b) Angenommen, der wahre Mittelwert ist 40 Minuten und die Dauer ist normalverteilt. Mit welcher Wahrscheinlichkeit liegt eine einzelne Installation in dem Intervall aus (a)? Warum ist das nicht 95 %?

  • Tipp
  • Lösung
  • Erklärung
  1. wie Aufgabe 1. (b) Eine einzelne Installation ist \(N(40, 5^2)\)- verteilt — nicht \(N(40, 5^2/64)\). Gesucht ist \(P(a \le X \le b)\) mit pnorm().
ki <- 42 + c(-1, 1) * qnorm(0.975) * 5 / sqrt(64)

#> [1] 40.77502 43.22498

diff(pnorm(ki, mean = 40, sd = 5))       # (b): P(a <= X <= b) für eine Installation
#> [1] 0.1789438

      ylab = "Dichte", main = "Einzelne Installation vs. Konfidenzintervall")

(a) \(42 \pm 1{,}96 \cdot 5/8 = 42 \pm 1{,}23\), also \([40{,}78;\ 43{,}22]\).

(b) \(P(40{,}78 \le X \le 43{,}22) \approx 0{,}18\) — weit weg von 95 %. Das Konfidenzintervall ist für den Mittelwert gebaut, dessen Standardfehler \(\sigma/\sqrt{64} = 0{,}625\) beträgt. Eine einzelne Installation streut mit \(\sigma = 5\), also achtmal so stark. Konfidenzintervalle sind keine Vorhersageintervalle für einzelne Beobachtungen. Hinzu kommt, dass das Intervall aus (a) den wahren Mittelwert 40 gar nicht enthält — es ist eines der 5 % „Fehlschläge”.

Aufgabe 3: Widerstände (Baron, Übung 9.12). Widerstände sind näherungsweise normalverteilt mit \(\sigma = 0{,}2\ \Omega\). 52 Widerstände haben den Mittelwert \(0{,}62\ \Omega\). Pareto-Zufallszahlen erzeugen Sie wie in Vorlesung 04 per Inversion: \(X = \sigma\, U^{-1/\theta}\). Orientieren Sie sich an fehlerseiten(). Achten Sie nicht nur auf die Gesamtüberdeckung, sondern auch auf die Aufteilung der Fehler auf beide Seiten.

rpareto <- function(n, sigma, theta) sigma * runif(n)^(-1 / theta)   # Inversion

pareto_seiten <- function(n, theta, R = 10000) {
  mu <- theta / (theta - 1)
  s  <- sqrt(theta / ((theta - 1)^2 * (theta - 2)))
  marge <- qnorm(0.975) * s / sqrt(n)
  r <- replicate(R, {
    xq <- mean(rpareto(n, sigma = 1, theta = theta))
    c(zu_hoch = xq - marge > mu, zu_tief = xq + marge < mu)
  })
  c(ueberdeckung = 1 - mean(colSums(r) > 0),
    zu_hoch = mean(r["zu_hoch", ]), zu_tief = mean(r["zu_tief", ]))
}

set.seed(3)
gitter <- expand.grid(n = c(10, 100, 1000), theta = c(3, 2.2))
cbind(gitter, round(t(mapply(pareto_seiten, gitter$n, gitter$theta)), 4))

Überraschend: Die Gesamtüberdeckung liegt über 95 % (rund 96 % bei \(\theta = 3\), rund 98 % bei \(\theta = 2{,}2\)). Das Verfahren wirkt also „zu vorsichtig” — tatsächlich ist es aber auf beiden Seiten falsch:

  • Zu tief liegt das Intervall fast nie. Der Mittelwert kann nicht weit unter \(\mu\) fallen, denn alle Werte sind mindestens \(\sigma = 1\).
  • Zu hoch liegt es dagegen in rund 1,5–3,7 % der Fälle — immer dann, wenn ein seltener, extrem großer Wert den Mittelwert nach oben zieht.

Die Varianz wird von diesen seltenen Extremen dominiert. In einer typischen Stichprobe kommen sie nicht vor; dort ist \(\bar X\) viel weniger variabel, als \(\sigma/\sqrt n\) unterstellt, und das Intervall ist unnötig breit.

Bei \(\theta = 3\) nähert sich die Aufteilung mit wachsendem \(n\) langsam dem symmetrischen Ideal (2,5 % / 2,5 %). Bei \(\theta = 2{,}2\) ist davon selbst bei \(n = 1000\) nichts zu sehen: Je näher \(\theta\) an 2 liegt (wo die Varianz unendlich wird), desto langsamer wirkt der zentrale Grenzwertsatz. „\(n\) groß genug” hängt also stark von der Verteilung ab — für Daten mit schweren Rändern wie Dateigrößen oder Antwortzeiten kann es sehr groß sein.

# [Vorlesung 04-02: Konfidenzintervalle]{style="color: red"}

Definition und Interpretation, allgemeine Konstruktion,
Konfidenzintervalle für einen Mittelwert und für die Differenz zweier
Mittelwerte, Wahl des Stichprobenumfangs (Baron, §9.2).

**Lernziele**

Nach dieser Vorlesung können Sie

- erklären, was ein Konfidenzniveau aussagt — und was nicht,
- aus einem erwartungstreuen, normalverteilten Schätzer ein
  Konfidenzintervall konstruieren,
- Konfidenzintervalle für einen Mittelwert und für die Differenz zweier
  Mittelwerte berechnen,
- per Simulation prüfen, ob ein Intervallverfahren sein
  Konfidenzniveau tatsächlich einhält,
- den Stichprobenumfang bestimmen, der eine vorgegebene Genauigkeit
  garantiert.

## [**Rückblick: Schätzer und Standardfehler**]{style="color: green"}

In der letzten Vorlesung haben wir Parameter **geschätzt**. Drei
Punkte daraus brauchen wir heute:

- Ein Schätzer $\hat\theta$ ist eine **Zufallsvariable** — jede
  Stichprobe liefert einen anderen Wert.
- **Erwartungstreu** heißt $E(\hat\theta) = \theta$: Der Schätzer
  liegt im Mittel richtig.
- Der **Standardfehler** $\sigma(\hat\theta)$ misst, wie stark er um
  $\theta$ schwankt.

Für den Stichprobenmittelwert gilt $E(\bar X) = \mu$ und
$\sigma(\bar X) = \sigma/\sqrt n$; nach dem zentralen Grenzwertsatz ist
$\bar X$ für großes $n$ näherungsweise normalverteilt. Eine kurze
Simulation mit $\mu = 50$, $\sigma = 8$ und $n = 25$ zeigt, was daraus
folgt:

```{r}
set.seed(1)
mu <- 50; sigma <- 8; n <- 25
xq <- replicate(10000, mean(rnorm(n, mu, sigma)))

c(mittel = mean(xq), sd = sd(xq), theorie_se = sigma / sqrt(n))
mean(abs(xq - mu) <= 1.96 * sigma / sqrt(n))   # Anteil innerhalb von 1.96 SE
```

In rund 95 % der Stichproben liegt $\bar X$ höchstens
$1{,}96\,\sigma/\sqrt n$ von $\mu$ entfernt. Dann liegt umgekehrt auch
$\mu$ höchstens $1{,}96\,\sigma/\sqrt n$ von $\bar X$ entfernt — und
genau das ist ein Konfidenzintervall. Diese Umkehrung ist die ganze
Idee der heutigen Vorlesung.

## [**Konfidenzintervalle: Idee und Konstruktion**]{style="color: green"}

**Von der Punktschätzung zum Intervall**

Ein Schätzwert $\hat\theta$ ist fast sicher **nicht** gleich $\theta$.
Statt einer einzelnen Zahl geben wir deshalb ein Intervall an, das den
Parameter mit hoher, bekannter Wahrscheinlichkeit enthält.

> **Definition (Baron 9.4).** Ein Intervall $[a, b]$ ist ein
> $(1-\alpha)100\,\%$-**Konfidenzintervall** für $\theta$, wenn
> $$P(a \le \theta \le b) = 1 - \alpha.$$
> $1 - \alpha$ heißt **Konfidenzniveau** (Überdeckungswahrscheinlichkeit).

**Was ist hier zufällig?**

Der Parameter $\theta$ ist **fest** — eine Eigenschaft der Population.
Zufällig sind die **Intervallgrenzen** $a$ und $b$, denn sie werden aus
der zufälligen Stichprobe berechnet. Das Konfidenzniveau ist also eine
Aussage über das **Verfahren**: Wiederholt man die Datenerhebung sehr
oft, überdecken $(1-\alpha)100\,\%$ der Intervalle den wahren Wert.

Das ist Barons Abbildung 9.2 — als Simulation mit 100 Stichproben
($n = 10$, $\mu = 50$, $\sigma = 8$) und 90-%-Intervallen:

```{r}
#| fig-width: 7
#| fig-height: 6
set.seed(13)
mu <- 50; sigma <- 8; n <- 10; niveau <- 0.90
z <- qnorm(1 - (1 - niveau) / 2)

grenzen <- t(replicate(100, {
  xq <- mean(rnorm(n, mu, sigma))
  c(unten = xq - z * sigma / sqrt(n), oben = xq + z * sigma / sqrt(n))
}))
trifft <- grenzen[, "unten"] <= mu & mu <= grenzen[, "oben"]

plot(NA, xlim = range(grenzen), ylim = c(1, 100), yaxt = "n",
     xlab = expression(mu), ylab = "Stichprobe",
     main = sprintf("100 Konfidenzintervalle (90 %%): %d überdecken mu", sum(trifft)))
segments(grenzen[, "unten"], 1:100, grenzen[, "oben"], 1:100,
         col = ifelse(trifft, "grey40", "firebrick"), lwd = ifelse(trifft, 1, 2.5))
abline(v = mu, col = "steelblue", lwd = 2)
```

Die roten Intervalle verfehlen $\mu$ — nicht wegen eines Fehlers,
sondern allein durch den Stichprobenzufall.

::: callout-warning
## Die häufigste Fehlinterpretation

**Falsch:** „Ich habe das 90-%-Intervall $[3, 6]$ berechnet; der
Parameter liegt mit 90 % Wahrscheinlichkeit darin."

Nach der Berechnung ist nichts mehr zufällig: $\theta$ liegt entweder in
$[3, 6]$ oder nicht. **Richtig:** „Das Verfahren liefert Intervalle,
die in 90 % aller Stichproben den wahren Wert enthalten." Die 90 %
beschreiben die **Methode**, nicht dieses eine Intervall.
:::

**Die allgemeine Konstruktion (Baron, §9.2.1)**

Ist $\hat\theta$ **erwartungstreu** und **normalverteilt**, dann ist

$$
Z = \frac{\hat\theta - \theta}{\sigma(\hat\theta)} \sim N(0, 1).
$$

$Z$ liegt mit Wahrscheinlichkeit $1-\alpha$ zwischen den Quantilen
$-z_{\alpha/2}$ und $z_{\alpha/2}$, wobei $z_{\alpha/2} = \Phi^{-1}(1 - \alpha/2)$
der Wert ist, der mit Wahrscheinlichkeit $\alpha/2$ überschritten wird:

$$
P\!\left(-z_{\alpha/2} \le \frac{\hat\theta - \theta}{\sigma(\hat\theta)} \le z_{\alpha/2}\right) = 1 - \alpha.
$$

Auflösen der Ungleichungen nach $\theta$ ergibt die zentrale Formel

$$
\boxed{\;\hat\theta \pm z_{\alpha/2}\cdot\sigma(\hat\theta)\;}
\qquad\text{(Baron, 9.3)}
$$

Man nennt $\hat\theta$ den **Mittelpunkt** und
$z_{\alpha/2}\cdot\sigma(\hat\theta)$ die **Fehlermarge** (*margin of
error*), wie sie bei Umfragen berichtet wird. Ist $\hat\theta$ nur
näherungsweise normalverteilt, ist auch das Intervall nur
näherungsweise ein $(1-\alpha)100\,\%$-Intervall.

```{r}
#| fig-width: 6
#| fig-height: 3.5
alpha <- 0.05
z <- qnorm(1 - alpha / 2)
curve(dnorm(x), from = -3.5, to = 3.5, lwd = 2, xlab = "z", ylab = "Dichte",
      main = expression("Standardnormalverteilung und " %+-% z[alpha/2]))
xs <- seq(-z, z, length.out = 200)
polygon(c(-z, xs, z), c(0, dnorm(xs), 0), col = "lightsteelblue", border = NA)
abline(v = c(-z, z), lty = 2)
text(0, 0.15, expression(1 - alpha))
text(c(-2.8, 2.8), 0.05, expression(alpha / 2))
```

**Quantile in R statt Tabelle**

Die Quantile aus Barons Tabelle A4 liefert `qnorm()`:

```{r}
niveaus <- c(0.80, 0.90, 0.95, 0.98, 0.99)
data.frame(niveau = niveaus, alpha = 1 - niveaus,
           z = round(qnorm(1 - (1 - niveaus) / 2), 3))
```

Merken sollte man sich $z_{0{,}05} = 1{,}645$ (90 %),
$z_{0{,}025} = 1{,}960$ (95 %) und $z_{0{,}005} = 2{,}576$ (99 %).

**Rezept (Baron, §9.2.1)**

(a) Einen erwartungstreuen Schätzer $\hat\theta$ finden.
(b) Prüfen, ob er (näherungsweise) normalverteilt ist.
(c) Seinen Standardfehler $\sigma(\hat\theta)$ bestimmen.
(d) Das Quantil $z_{\alpha/2}$ bestimmen (`qnorm(1 - alpha/2)`).
(e) $\hat\theta \pm z_{\alpha/2}\,\sigma(\hat\theta)$ berechnen.

## [**Konfidenzintervall für einen Mittelwert ($\sigma$ bekannt)**]{style="color: green"}

Für $\theta = \mu$ ist $\hat\theta = \bar X$ erwartungstreu mit
$\sigma(\bar X) = \sigma/\sqrt n$. Normalverteilt ist $\bar X$ in zwei
Fällen:

1. Die Daten sind normalverteilt — dann ist $\bar X$ exakt normal.
2. Der Stichprobenumfang $n$ ist groß — dann ist $\bar X$ nach dem
   zentralen Grenzwertsatz näherungsweise normal.

$$
\bar X \pm z_{\alpha/2}\,\frac{\sigma}{\sqrt n}
\qquad\text{(Baron, 9.5)}
$$

```{r}
ki_mittelwert <- function(x, sigma, niveau = 0.95) {
  z <- qnorm(1 - (1 - niveau) / 2)
  marge <- z * sigma / sqrt(length(x))
  c(mittelwert = mean(x), marge = marge,
    unten = mean(x) - marge, oben = mean(x) + marge)
}
```

**Beispiel (Baron, Bsp. 9.13).** Messungen $2{,}5;\ 7{,}4;\ 8{,}0;\ 4{,}5;\ 7{,}4;\ 9{,}2$
mit normalverteilten Messfehlern; das Messgerät garantiert
$\sigma = 2{,}2$. Gesucht ist ein 95-%-Konfidenzintervall für $\mu$.

```{r}
messung <- c(2.5, 7.4, 8.0, 4.5, 7.4, 9.2)
round(ki_mittelwert(messung, sigma = 2.2, niveau = 0.95), 2)
```

Ergebnis: $6{,}50 \pm 1{,}76$, also $[4{,}74;\ 8{,}26]$ — wie bei
Baron.

**Hält das Verfahren sein Versprechen?**

Wir prüfen die Überdeckung per Simulation. Bei normalverteilten Daten
sollte sie für **jedes** $n$ bei 95 % liegen:

```{r}
ueberdeckung <- function(zufall, mu, sigma, n, R = 10000, niveau = 0.95) {
  z <- qnorm(1 - (1 - niveau) / 2)
  treffer <- replicate(R, {
    xq <- mean(zufall(n))
    abs(xq - mu) <= z * sigma / sqrt(n)
  })
  mean(treffer)
}

set.seed(14)
sapply(c(n_3 = 3, n_10 = 10, n_50 = 50),
       function(n) ueberdeckung(function(k) rnorm(k, 6.5, 2.2), 6.5, 2.2, n))
```

**Und bei nicht normalverteilten Daten?**

Baron warnt: Für kleine Stichproben aus nicht normalverteilten
Populationen gilt die Formel nicht. Wie äußert sich das? Wir verwenden
stark schiefe exponentialverteilte Daten ($\mu = \sigma = 1$) und zählen
getrennt, wie oft das Intervall **zu hoch** bzw. **zu tief** liegt:

```{r}
fehlerseiten <- function(n, R = 20000, niveau = 0.95) {
  z <- qnorm(1 - (1 - niveau) / 2)
  r <- replicate(R, {
    xq <- mean(rexp(n, rate = 1))
    marge <- z * 1 / sqrt(n)
    c(zu_hoch = xq - marge > 1, zu_tief = xq + marge < 1)
  })
  c(ueberdeckung = 1 - mean(colSums(r) > 0),
    zu_hoch = mean(r["zu_hoch", ]), zu_tief = mean(r["zu_tief", ]))
}

set.seed(15)
round(t(sapply(c(n_5 = 5, n_10 = 10, n_30 = 30, n_100 = 100, n_1000 = 1000),
               fehlerseiten)), 4)
```

Die **Gesamtüberdeckung** liegt erstaunlich nah bei 95 % — aber die
Fehler sind **einseitig**: Bei $n = 5$ liegt das Intervall in rund 4 %
der Fälle zu hoch und fast nie zu tief. Erst bei großem $n$ verteilen
sich die Fehler gleichmäßig auf beide Seiten, so wie es bei einem
symmetrischen Intervall sein soll. Wer aus einem solchen Intervall
einseitige Schlüsse zieht (z. B. „$\mu$ ist höchstens …"), irrt sich
viel häufiger als in 2,5 % der Fälle.

```{r}
#| fig-height: 3.5

       main = bquote("Verteilung von" ~ bar(X) ~ "bei" ~ n == .(n)),
```

## [**Konfidenzintervall für die Differenz zweier Mittelwerte**]{style="color: green"}

Oft vergleicht man zwei Populationen: zwei Server, zwei Algorithmen,
zwei Konfigurationen, vor und nach einem Update. Aus jeder Population
wird **unabhängig** eine Stichprobe gezogen,
$X_1, \dots, X_n$ und $Y_1, \dots, Y_m$. Gesucht ist ein
Konfidenzintervall für $\theta = \mu_X - \mu_Y$. Wir folgen dem Rezept:

(a) Schätzer: $\hat\theta = \bar X - \bar Y$.
(b) Erwartungstreu: $E(\bar X - \bar Y) = \mu_X - \mu_Y$.
(c) Normalverteilt, wenn beide Populationen normal sind oder beide
    Stichproben groß sind.
(d) Wegen der Unabhängigkeit addieren sich die Varianzen:
    $\sigma(\hat\theta) = \sqrt{\sigma_X^2/n + \sigma_Y^2/m}$.
(e) Damit:

$$
\bar X - \bar Y \pm z_{\alpha/2}\sqrt{\frac{\sigma_X^2}{n} + \frac{\sigma_Y^2}{m}}
\qquad\text{(Baron, 9.6)}
$$

::: callout-important
## Varianzen addieren sich — auch bei einer Differenz

$\operatorname{Var}(\bar X - \bar Y) = \operatorname{Var}(\bar X) + \operatorname{Var}(\bar Y)$,
nicht die Differenz der Varianzen. Die Unsicherheit beider
Stichproben kommt zusammen.
:::

```{r}
ki_differenz <- function(xq, yq, sigma_x, sigma_y, n, m, niveau = 0.95) {
  z <- qnorm(1 - (1 - niveau) / 2)
  marge <- z * sqrt(sigma_x^2 / n + sigma_y^2 / m)
  c(differenz = xq - yq, marge = marge,
    unten = xq - yq - marge, oben = xq - yq + marge)
}
```

**Beispiel (Baron, Bsp. 9.14): Wirkung eines Hardware-Upgrades.** Ein
Prozess läuft 50-mal vor und 50-mal nach einem Upgrade. Die mittlere
Laufzeit beträgt 8,5 Minuten vorher und 7,2 Minuten nachher; die
Standardabweichung ist aus Erfahrung $\sigma = 1{,}8$ Minuten (in
beiden Fällen). Gesucht ist ein 90-%-Konfidenzintervall für die
Verkürzung der mittleren Laufzeit.

```{r}
round(ki_differenz(xq = 8.5, yq = 7.2, sigma_x = 1.8, sigma_y = 1.8,
                   n = 50, m = 50, niveau = 0.90), 2)
```

Das Upgrade verkürzt die mittlere Laufzeit um 1,3 Minuten, mit einer
90-%-Fehlermarge von 0,6 Minuten: $[0{,}7;\ 1{,}9]$. Da das Intervall
die 0 nicht enthält, ist eine echte Verbesserung plausibel.

Die Laufzeiten müssen dafür nicht normalverteilt sein — bei
$n = m = 50$ sorgt der zentrale Grenzwertsatz für die Normalität von
$\bar X - \bar Y$. Eine Simulation mit schiefen (gammaverteilten)
Laufzeiten bestätigt das:

```{r}

# Gammaverteilte Laufzeiten mit Mittelwert 8.5 bzw. 7.2 und sd 1.8

treffer <- replicate(10000, {
```

## [**Wahl des Stichprobenumfangs**]{style="color: green"}

Jedes Konfidenzintervall dieser Vorlesung hat die Form
**Mittelpunkt ± Marge**. Damit lässt sich die Frage umdrehen: *Wie groß
muss die Stichprobe sein, damit die Marge höchstens $\Delta$ beträgt?*
Für den Mittelwert ist

$$
z_{\alpha/2}\frac{\sigma}{\sqrt n} \le \Delta
\quad\Longleftrightarrow\quad
n \ge \left(\frac{z_{\alpha/2}\,\sigma}{\Delta}\right)^2
\qquad\text{(Baron, 9.8)}
$$

Das Ergebnis wird **immer aufgerundet** — beim Abrunden wäre die Marge
größer als $\Delta$.

```{r}
n_benoetigt <- function(sigma, delta, niveau = 0.95) {
  z <- qnorm(1 - (1 - niveau) / 2)
  ceiling((z * sigma / delta)^2)
}
```

**Beispiel (Baron, Bsp. 9.15).** Das Intervall aus Bsp. 9.13 hatte die
Marge 1,76 — zu breit. Wie groß muss die Stichprobe sein, damit die
95-%-Marge höchstens 0,4 beträgt?

```{r}
(qnorm(0.975) * 2.2 / 0.4)^2             # exakter Wert
n_benoetigt(sigma = 2.2, delta = 0.4)    # aufgerundet
```

Man braucht mindestens 117 Messungen.

**Was treibt den Stichprobenumfang?**

Ein großes $n$ ist nötig für

- eine **kleine Marge** $\Delta$,
- ein **hohes Konfidenzniveau** (kleines $\alpha$),
- **stark streuende Daten** (großes $\sigma$).

Weil $\Delta$ nur mit $1/\sqrt n$ fällt, muss man den
Stichprobenumfang **vervierfachen**, um die Marge zu **halbieren** —
dieselbe $1/\sqrt n$-Regel wie beim Monte-Carlo-Fehler.

```{r}
#| fig-width: 7
#| fig-height: 4
n_seq <- 1:200
plot(n_seq, qnorm(0.975) * 2.2 / sqrt(n_seq), type = "l", lwd = 2, log = "y",
     xlab = "Stichprobenumfang n", ylab = "Marge (log. Skala)",
     main = "95-%-Marge für sigma = 2.2")
lines(n_seq, qnorm(0.995) * 2.2 / sqrt(n_seq), lty = 2)
lines(n_seq, qnorm(0.95)  * 2.2 / sqrt(n_seq), lty = 3)
abline(h = 0.4, col = "red"); abline(v = 117, col = "red", lty = 3)
legend("topright", c("99 %", "95 %", "90 %"), lty = c(2, 1, 3), lwd = c(1, 2, 1),
       bty = "n")
```

```{r}
outer(c(sigma_1 = 1, sigma_2 = 2, sigma_5 = 5),
      c(delta_1 = 1, delta_0.5 = 0.5, delta_0.1 = 0.1),
```

## Ausblick: unbekanntes $\sigma$

Alle Intervalle dieser Vorlesung setzen ein **bekanntes** $\sigma$
voraus — etwa aus der Genauigkeit eines Messgeräts oder aus vielen
historischen Daten. Meist ist $\sigma$ aber unbekannt und muss durch
$s$ geschätzt werden. Für große Stichproben ändert sich fast nichts;
für kleine normalverteilte Stichproben ersetzt man $z_{\alpha/2}$ durch
das Quantil der **$t$-Verteilung** (Baron, §9.3; `t.test()`). Das ist
Thema der nächsten Vorlesung.
:::

**Aufgabe 5: Überdeckung selbst messen.** Schreiben Sie eine Funktion,
die die Überdeckung des Intervalls $\bar X \pm z_{\alpha/2}\sigma/\sqrt n$
(95 %) für Pareto-Daten mit $\sigma = 1$ schätzt und — wie in der
Vorlesung — getrennt zählt, wie oft das Intervall zu hoch bzw. zu tief
liegt. Erwartungswert und Varianz sind bekannt:
$\mu = \frac{\theta}{\theta - 1}$,
$\operatorname{Var}(X) = \frac{\theta}{(\theta-1)^2(\theta-2)}$.
Untersuchen Sie $\theta = 3$ und $\theta = 2{,}2$ für
$n = 10, 100, 1000$. Was fällt auf?

:::: {.callout-tip collapse="true"}
## Lösung zu Aufgabe 5

::: panel-tabset
### Tipp

Pareto-Zufallszahlen erzeugen Sie wie in Vorlesung 04 per Inversion:
$X = \sigma\, U^{-1/\theta}$. Orientieren Sie sich an `fehlerseiten()`. Achten Sie nicht nur auf die Gesamtüberdeckung,
sondern auch auf die Aufteilung der Fehler auf beide Seiten.

### Lösung

```{r}
rpareto <- function(n, sigma, theta) sigma * runif(n)^(-1 / theta)   # Inversion

pareto_seiten <- function(n, theta, R = 10000) {
  mu <- theta / (theta - 1)
  s  <- sqrt(theta / ((theta - 1)^2 * (theta - 2)))
  marge <- qnorm(0.975) * s / sqrt(n)
  r <- replicate(R, {
    xq <- mean(rpareto(n, sigma = 1, theta = theta))
    c(zu_hoch = xq - marge > mu, zu_tief = xq + marge < mu)
  })
  c(ueberdeckung = 1 - mean(colSums(r) > 0),
    zu_hoch = mean(r["zu_hoch", ]), zu_tief = mean(r["zu_tief", ]))
}

set.seed(3)
gitter <- expand.grid(n = c(10, 100, 1000), theta = c(3, 2.2))
cbind(gitter, round(t(mapply(pareto_seiten, gitter$n, gitter$theta)), 4))
```

### Erklärung

Überraschend: Die Gesamtüberdeckung liegt **über** 95 % (rund 96 % bei
$\theta = 3$, rund 98 % bei $\theta = 2{,}2$). Das Verfahren wirkt also
„zu vorsichtig" — tatsächlich ist es aber auf **beiden** Seiten falsch:

- **Zu tief** liegt das Intervall fast nie. Der Mittelwert kann nicht
  weit unter $\mu$ fallen, denn alle Werte sind mindestens $\sigma = 1$.
- **Zu hoch** liegt es dagegen in rund 1,5–3,7 % der Fälle — immer dann,
  wenn ein seltener, extrem großer Wert den Mittelwert nach oben zieht.

Die Varianz wird von diesen seltenen Extremen dominiert. In einer
typischen Stichprobe kommen sie nicht vor; dort ist $\bar X$ viel
weniger variabel, als $\sigma/\sqrt n$ unterstellt, und das Intervall ist
unnötig breit.

Bei $\theta = 3$ nähert sich die Aufteilung mit wachsendem $n$
langsam dem symmetrischen Ideal (2,5 % / 2,5 %). Bei $\theta = 2{,}2$
ist davon selbst bei $n = 1000$ nichts zu sehen: Je näher $\theta$ an 2
liegt (wo die Varianz unendlich wird), desto langsamer wirkt der
zentrale Grenzwertsatz. „$n$ groß genug" hängt also stark von der
Verteilung ab — für Daten mit schweren Rändern wie Dateigrößen oder
Antwortzeiten kann es sehr groß sein.
:::

## [**Das Minimum, das Sie ohne Hilfe beherrschen sollten**]{style="color: green"}

**Begriffe** — Konfidenzintervall, Konfidenzniveau,
Überdeckungswahrscheinlichkeit, Fehlermarge, Quantil $z_{\alpha/2}$,
zentraler Grenzwertsatz, Stichprobenumfangsplanung.

**Formeln**

| Situation | Formel |
|----------------------------------|----------------------------------|
| Allgemeines Konfidenzintervall | $\hat\theta \pm z_{\alpha/2}\,\sigma(\hat\theta)$ |
| Mittelwert, $\sigma$ bekannt | $\bar X \pm z_{\alpha/2}\,\sigma/\sqrt n$ |
| Differenz zweier Mittelwerte | $\bar X - \bar Y \pm z_{\alpha/2}\sqrt{\sigma_X^2/n + \sigma_Y^2/m}$ |
| Stichprobenumfang | $n \ge (z_{\alpha/2}\,\sigma/\Delta)^2$, aufrunden |

**R** — `qnorm()`, `pnorm()`, `mean()`, `replicate()`, `ceiling()`,
`segments()`, `curve()`, `polygon()`, `mapply()`, `expand.grid()`.

**Achtung:**

1.  **Konfidenzintervall falsch deuten.** Die 95 % beziehen sich auf
    das Verfahren, nicht auf das eine berechnete Intervall.

2.  **Konfidenz- mit Vorhersageintervall verwechseln.** Das Intervall
    gilt für den Mittelwert $\mu$, nicht für einzelne Beobachtungen.

3.  **$z_\alpha$ statt $z_{\alpha/2}$.** Für ein zweiseitiges
    95-%-Intervall braucht man `qnorm(0.975)` = 1,96, nicht
    `qnorm(0.95)` = 1,645.

4.  **Varianzen subtrahieren.** Bei $\bar X - \bar Y$ werden die
    Varianzen **addiert**.

5.  **Stichprobenumfang abrunden.** Immer `ceiling()`.

6.  **Formel ohne Voraussetzung anwenden.** $\bar X \pm z\,\sigma/\sqrt n$
    braucht normalverteilte Daten oder ein großes $n$ — bei kleinen,
    schiefen Stichproben sind die Fehler einseitig.

7.  **Nur die Gesamtüberdeckung prüfen.** Ein Verfahren mit 96 %
    Überdeckung kann trotzdem schlecht sein, wenn alle Fehler auf einer
    Seite liegen.
